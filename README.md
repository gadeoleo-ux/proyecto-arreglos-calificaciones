# Sistema de Calificaciones con Vectores

## Descripción
Programa de consola en Python que administra las calificaciones de cinco estudiantes usando dos vectores (listas) paralelos: uno con los nombres y otro con las notas. Un menú interactivo permite consultar, calcular y modificar los datos.

## Objetivo
Aplicar los conceptos de arreglo, índice y vector del Capítulo IX de Introducción a la Programación para almacenar, consultar, modificar y procesar un conjunto de datos.

## Lenguaje utilizado
Python 3

## Funcionalidades desarrolladas
- Mostrar todas las calificaciones con su posición en el vector.
- Consultar la calificación de un estudiante por su índice, validando que la posición exista.
- Calcular el promedio del grupo.
- Encontrar la nota más alta y la más baja, con el nombre del estudiante.
- Contar aprobados (nota igual o mayor a 70) y reprobados.
- Modificar una calificación y mostrar el vector actualizado.

## Instrucciones para ejecutar el programa
1. Instalar Python 3 desde https://www.python.org/downloads/
2. Descargar o clonar este repositorio:
   `git clone https://github.com/gadeoleo-ux/proyecto-arreglos-calificaciones.git`
3. Entrar a la carpeta del proyecto y ejecutar:
   `python sistema_calificaciones.py`
4. Elegir una opción del menú escribiendo su número y presionando Enter.
